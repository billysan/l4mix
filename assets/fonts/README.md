# BigBlue Terminal

The dashboard bundles the unmodified **BigBlueTermPlus Nerd Font Mono Regular**
font, based on BigBlue Terminal by **VileR (© 2015)** and patched by Nerd Fonts.
The Plus variant supplies an extended character set.

Source: https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/BigBlueTerminal
Font file: https://github.com/ryanoasis/nerd-fonts/blob/master/patched-fonts/BigBlueTerminal/BigBlueTermPlusNerdFontMono-Regular.ttf
